A two-line explanation of a traffic jam for a 10-year-old: the jam is a slinky stretched down the road, and one driver's brake tap is a squeeze that crawls backwards from bumper to bumper until it stops you, long after the car that caused it has gone. The second line does the honest accounting — coils stand for the gaps between cars and the squeeze for the brake tap, but a spring keeps every coil, so exits and lane changes sit outside the picture. `main.py` copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`) as bytes, so every run writes identical output.

## Run it

```sh
python3 main.py
```
